What it can inspect

      
The same core runtime powers the hosted demo, CLI, API and MCP entry points.

      

        
Deep URL intelligence
Redirects, DNS, TLS, metadata, structured data, crawling, links and freshness signals.

        
Entity & brand resolution
Organizations, people, social profiles, public contacts, technologies and brand evidence.

        
SEO, security & trust
SEO posture, security headers, quality, transparency and public compliance indicators.

        
RAG & knowledge export
Provenance-aware facts and documents ready for downstream retrieval and AI workflows.

        
Monitoring & comparison
Snapshots, diffs, URL comparison, batch enrichment and evidence-first reports.

        
Agent integration
Use the CLI, HTTP service, Docker runtime or MCP server depending on your stack.

      

    


    

      
Run locally with the CLI

      
Local usage is not subject to the hosted demo quota.

      

        
Quick start

        
git clone https://github.com/vpicciuolo/url-intelligence-agent.git
cd url-intelligence-agent
npm install
npm run build

# Full investigation
node dist/src/cli.js investigate https://example.com

# SEO
node dist/src/cli.js seo https://example.com

# Security
node dist/src/cli.js security https://example.com

# Social profiles
node dist/src/cli.js socials https://example.com

# Technology detection
node dist/src/cli.js technologies https://example.com

      

    


    

      
Use it as an HTTP API

      
Start the server locally, or call the public Hugging Face demo endpoint subject to the 24-hour quota.

      

        
Local server

        
npm run serve
# default local API: http://127.0.0.1:8787

curl "http://127.0.0.1:8787/investigate?url=https://example.com"
curl "http://127.0.0.1:8787/action/audit_seo?url=https://example.com"
curl "http://127.0.0.1:8787/health"
curl "http://127.0.0.1:8787/actions"

      

      

        
Hosted demo API

        
curl "https://vpicciuolo-url-intelligence-agent.hf.space/investigate?url=https://example.com"

# 1 analysis request per HF account / anonymous IP every 24h

      

    


    

      
Run as an MCP server

      
Expose the agent actions to compatible AI clients and agent runtimes through the project MCP entry point.

      

        
MCP

        
npm run mcp

# or directly
node dist/src/cli.js mcp
