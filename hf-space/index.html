One agent. Multiple intelligence layers.

Built as a reusable TypeScript runtime with CLI, HTTP API and MCP entry points for local, server and agentic workflows.

Deep URL Intelligence

Crawl, redirects, DNS, TLS, metadata, structured data, external links and content freshness.

Entity & Brand Resolution

Resolve organizations, people, social profiles, public contacts, technologies and brand signals with evidence.

SEO, Security & Trust

Audit SEO, security headers, quality, accessibility, transparency and public compliance signals.

RAG & Knowledge Export

Export provenance-aware documents and facts for downstream retrieval, research and AI workflows.

API + MCP

Run as an HTTP service or MCP server and expose the same intelligence actions to other tools and agents.

Monitoring & Batch

Watch URLs, diff snapshots, process URL lists concurrently and generate Markdown, HTML and JSON reports.
