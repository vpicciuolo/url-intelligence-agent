How to read a result

      
The interface is designed around a simple rule: confidence should come from observable evidence, not from the model sounding confident. The result keeps uncertainty visible and gives you the material needed to verify important claims yourself.

      

        
1. Evidence-linked confidence
Evidence fields carry a value, confidence score, extraction method and source URLs. The UI surfaces all four together.

        
2. Disagreement stays visible
If the runtime reports contradictions, the result is explicitly marked as disputed. Contradictions are shown before the detailed output rather than being buried.

        
3. Time matters
The observation timestamp is shown when available. Public web content changes, so a result is evidence observed at a point in time, not permanent truth.

        
4. Sources remain openable
Unique public source URLs discovered inside the result are collected in one place. Open them and inspect why a claim received its confidence.

        
5. No forced consensus
No explicit contradiction does not automatically prove that every source agrees. The UI states exactly that instead of overstating consensus.

        
6. Raw output remains available
The structured view is for humans. The complete raw JSON remains underneath for developers, reproducibility and audit workflows.

Frequently asked questions

      
These answers are deliberately precise about what the agent can prove, what it only observes and where uncertainty remains.

      

        
Where does the confidence score come from?
Evidence fields include the extracted value, a confidence number, the extraction method and source URLs. Confidence is therefore shown next to observable evidence. It should not be interpreted as the AI simply saying “I am confident.”

        
What happens when two sources disagree?
The full investigation result contains a contradictions list. When contradictions are present, the web result shows a disputed-evidence warning before the normal sections. The sources stay openable so you can inspect why the evidence differs.

        
Does “no contradiction found” mean all sources agree?
No. It means this run did not report an explicit contradiction. The interface intentionally avoids turning absence of a detected conflict into a stronger consensus claim.

        
Can I see when the information was observed?
Yes when the action returns an observation timestamp, especially full investigations and snapshots. The result summary displays it. Public websites can change after that time.

        
Can I open the original evidence?
Yes. EvidenceField source URLs and other public URLs found in the result are collected into an “Open sources” section. The complete JSON is also preserved below the human-readable view.

        
Why can a result change between runs?
The agent observes the live public web. Pages, DNS, headers, structured data, social links, technologies and policies can change. Crawl configuration and availability can also affect what evidence is observable at a given time.

        
Are SEO, security, trust or compliance scores definitive?
No. They are explainable observations of public signals. Security audit is not penetration testing, compliance signals are not legal advice, and trust scoring is not a guarantee about a person or organization.

        
What URLs can be investigated?
Public HTTP/HTTPS URLs. The runtime validates destinations and deliberately blocks localhost/private network destinations. It does not intentionally bypass authentication, CAPTCHAs or access controls.

        
Why does the hosted demo have a limit?
The public Space is for testing. A normal signed-in Hugging Face account gets one hosted analysis every 24 hours. Clone or self-host the MIT-licensed project for unrestricted usage under your own infrastructure limits.

        
What is the difference between the hosted demo and the full runtime?
The hosted demo exposes a controlled read-only subset. The repository contains all 34 actions plus CLI, HTTP API, Docker, local MCP, monitoring, batch operations and optional AI reasoning.
