Connect your AI directly with Remote MCP

      
The Space exposes a public Streamable HTTP MCP endpoint. Compatible remote-MCP clients can discover the available URL intelligence tools and call them directly from an AI conversation. This includes clients and platforms with remote MCP support such as Claude and ChatGPT custom apps/connectors where the feature is available.

      

        Public Remote MCP endpoint
        
https://vpicciuolo-url-intelligence-agent.hf.space/mcp

        
Transport: Streamable HTTP · Public read-only demo tools · No API key required for connection · One analysis tool call per MCP session every 24 hours. Tool discovery, initialization and health checks do not consume the analysis allowance.

        

          
ChatGPT
In a ChatGPT workspace/account with custom MCP app support, enable developer/custom app mode, create an app, paste the endpoint above, choose no authentication for this public demo, scan tools, then ask ChatGPT to investigate a URL using the connected app.

          
Claude / other MCP clients
Add the URL above as a remote Streamable HTTP MCP server. After initialization, the client can discover the public URL intelligence tools and call one analysis for the demo session.

        

        
Protocol test
curl -i https://vpicciuolo-url-intelligence-agent.hf.space/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"test-client","version":"1.0"}}}'

      

    


    

      
Evidence-first web intelligence capabilities

      
The same core runtime powers the hosted interface, CLI, HTTP API, Docker service and MCP transports.

      

        
Deep URL crawling & mapping
Redirects, robots policy, sitemaps, multi-page crawling, links, metadata, structured data and freshness signals.

        
Entity & brand resolution
Organizations, people, products, public profiles, logos, brand signals and evidence-linked identity resolution.

        
SEO, security & trust audits
Search metadata, canonical/Open Graph signals, crawl discoverability, HTTP security headers, transparency and public trust indicators.

        
Social & contact discovery
Normalize public social profiles, emails, phone numbers and important contact/about pages from observable evidence.

        
Technology intelligence
Detect public web technologies and implementation signals using deterministic fingerprints and confidence scoring.

        
RAG, monitoring & reports
Generate provenance-aware knowledge exports, snapshots, diffs, structured data and branded intelligence reports.

      

    


    

      
Run the agent locally with the CLI

      
Clone the MIT-licensed repository for unrestricted local use, development, automation and self-hosting.

      
Quick start
git clone https://github.com/vpicciuolo/url-intelligence-agent.git
cd url-intelligence-agent
npm install
npm run build

node dist/src/cli.js investigate https://example.com
node dist/src/cli.js seo https://example.com
node dist/src/cli.js security https://example.com
node dist/src/cli.js socials https://example.com
node dist/src/cli.js technologies https://example.com

    


    

      
HTTP API, Docker and local MCP

      
Use the runtime as a service or integrate it into other agent stacks. The hosted web analysis requires Hugging Face login; the public remote MCP demo has its own session quota.

      

        
HTTP API
npm run serve

Endpoints include /health, /actions, /investigate and /action/:name.

        
Local MCP
npm run mcp

Starts the stdio MCP server for compatible local AI clients and development tools.

        
Docker
Build and run the same Node.js runtime as a portable container for private infrastructure or production integrations.
