# Contributing

Contributions are welcome.

Useful areas include URL safety, deterministic extraction, entity resolution, evidence scoring, technology detection, social-profile verification, benchmarks, MCP interoperability, report UX and new agent profiles.

Before submitting a pull request:

1. Run `npm run typecheck`.
2. Run `npm test`.
3. Add tests for new deterministic behavior.
4. Keep AI inference optional when possible.
5. Do not add scraping behavior that bypasses authentication or access controls.
6. Preserve evidence/provenance in new intelligence fields.

Good first contributions can include new page classifiers, additional structured-data handling, stronger contradiction detection, report improvements and benchmark fixtures.
