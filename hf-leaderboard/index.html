Independent baseline methodology

External tools are installed from pinned public package versions and exercised through their documented public APIs. Their upstream source is not modified. Adapter code only translates each tool's native outputs/errors into the benchmark's common prediction schema.

  1. url-metadata 5.12.0 uses its network-only probe and built-in request-filtering-agent SSRF controls.
  2. link-preview-js 5.0.0 uses its documented resolveDNSHost protection and manual redirect validation.
  3. Raw predictions and scorer summaries are published with the Dataset for inspection.
