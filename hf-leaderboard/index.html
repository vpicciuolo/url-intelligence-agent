How to submit

The leaderboard is open to other tools. Submissions are reviewed for reproducibility before publication.

  1. Run your analyzer on the pinned benchmark revision.
  2. Generate JSONL predictions and score them with the included evaluator.
  3. Publish the exact tool version/commit and reproduction command.
  4. Open a Benchmark Submission issue with predictions and scorer output.

What is measured

Action classification, HTTP status families, redirects, content kinds, invalid input handling, URL normalization and reject/block safety including SSRF/private-network vectors.
